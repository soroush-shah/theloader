# theloader

ابزاری برای دانلود **عکس‌های باکیفیت** یک سایت (مثل تکسچرها)، که هر عکس را **در پوشه‌ی دسته‌بندی خودش** ذخیره می‌کند.

> A tool that downloads the high-resolution images of a website (e.g. textures at `/textures/<id>`) into folders named after the site's own categories.

```
downloads/
  Concrete/
    12_Rough Concrete_1.jpg   (2048x2048)
    12_Rough Concrete_2.png
    13_Smooth Concrete.jpg
  Stone/
    40_Sandstone.jpg          (4096x2048)
    41_Marble.jpg
  manifest.csv               ← فهرست همه‌ی فایل‌ها: آدرس، ابعاد، صفحه‌ی منبع
```

## چه کار می‌کند

1. **صفحه‌ها را پیدا می‌کند** با یکی از این روش‌ها:
   - بازه‌ی شماره‌ها (`--ids 1-500`)
   - `sitemap.xml` (`--sitemap`)
   - گشتن کل سایت (`--crawl`)
   - فایل فهرست آدرس‌ها (`--urls`)
2. **از هر صفحه** این‌ها را می‌خواند:
   - عنوان
   - **دسته‌بندی**: به ترتیب از breadcrumb، داده‌های JSON-LD، لینک‌های `/category/`، یا انتخابگری که خودتان بدهید
   - همه‌ی عکس‌های صفحه
3. **باکیفیت‌ترین نسخه‌ی هر عکس** را پیدا می‌کند:
   - لینک‌های دانلود مستقیم
   - بزرگ‌ترین گزینه در `srcset`
   - عکس‌های lazy-load (`data-src` و ویژگی‌های مشابه)
   - حذف پسوند اندازه، مثل `-300x300`
   - حذف پارامترهای کوچک‌کننده، مثل `?w=400`
   - جایگزینی پوشه‌هایی مثل `/thumbs/`
4. **فقط سرِ فایل** را دانلود می‌کند تا ابعاد عکس را بفهمد. عکس‌های کوچک‌تر از ۶۰۰ پیکسل اصلاً کامل دانلود نمی‌شوند.
5. عکس‌های **تکراری** را حذف می‌کند (با مقایسه‌ی محتوای فایل). لوگو و آیکون‌ها را هم کنار می‌گذارد.
6. اگر وسط کار قطع شود، دفعه‌ی بعد **از همان‌جا ادامه می‌دهد**. صفحه‌هایی که در `manifest.csv` هستند دوباره دانلود نمی‌شوند.

## روش کار، قدم به قدم

**قدم ۱: آزمایش.** چند صفحه را تحلیل کنید. در این حالت چیزی ذخیره نمی‌شود:

```bash
python theloader.py https://YOUR-SITE.com --ids 1,2,3 --probe
```

خروجی برای هر صفحه دسته‌بندی، عنوان، و همه‌ی عکس‌ها را با ابعادشان نشان می‌دهد. عکس‌های `KEEP` دانلود می‌شوند و عکس‌های `small` نه.

**قدم ۲:** اگر دسته‌بندی یا عکس‌ها درست تشخیص داده نشدند، تنظیمات بخش «تنظیم برای سایت خودتان» را ببینید.

**قدم ۳: دانلود اصلی.**

```bash
python theloader.py https://YOUR-SITE.com --ids 1-2000
```

اگر نمی‌دانید شماره‌ها تا کجا می‌روند، بگذارید خود ابزار صفحه‌ها را پیدا کند:

```bash
python theloader.py https://YOUR-SITE.com --sitemap
```

```bash
python theloader.py https://YOUR-SITE.com --crawl
```

شماره‌هایی که صفحه ندارند فقط با پیام `✗ page not available` رد می‌شوند و مشکلی ایجاد نمی‌کنند.

## گزینه‌های مهم

| گزینه | کار |
|---|---|
| `--min-size 600` | حداقل ابعاد. پیش‌فرض: **ضلع کوچک‌تر** عکس باید حداقل ۶۰۰ پیکسل باشد |
| `--size-mode max` | به‌جای ضلع کوچک‌تر، ضلع بزرگ‌تر را با حداقل مقایسه می‌کند |
| `--best-only` | از هر تکسچر فقط بزرگ‌ترین عکس را نگه می‌دارد |
| `--item-folders` | برای هر تکسچر یک زیرپوشه‌ی جدا بسازد. پیش‌فرض: همه‌ی تکسچرهای یک دسته در یک پوشه، مثل `Stone/40_Sandstone.jpg` |
| `--out FOLDER` | پوشه‌ی ذخیره |
| `--limit 20` | حداکثر تعداد صفحه‌ها (برای آزمایش) |
| `--workers 4` | تعداد صفحه‌هایی که هم‌زمان پردازش می‌شوند |
| `--delay 0.2` | مکث بین درخواست‌ها، تا به سرور فشار نیاید |
| `--item-url` | الگوی آدرس صفحه‌ها. پیش‌فرض: `{base}/textures/{id}` |
| `--item-pattern` | الگوی regex برای تشخیص صفحه‌ی تکسچر |
| `--render` | باز کردن صفحه با مرورگر واقعی، برای سایت‌هایی که با جاوااسکریپت ساخته شده‌اند (`pip install playwright`) |
| `--cookies "..."` | برای صفحه‌هایی که ورود به حساب لازم دارند |

## تنظیم برای سایت خودتان

اگر دسته‌بندی درست تشخیص داده نشد، انتخابگر CSS آن را بدهید:

```bash
python theloader.py https://YOUR-SITE.com --ids 1-3 --probe --category-selector ".texture-category a"
```

پیدا کردن انتخابگر: در کروم روی اسم دسته‌بندی راست‌کلیک کنید، **Inspect** را بزنید و اسم کلاس آن را ببینید.

برای این موارد هم گزینه هست:

- **عکس‌های بخش‌های دیگر صفحه هم برداشته می‌شوند** (مثل «تکسچرهای مشابه»): جست‌وجو را به بخش اصلی صفحه محدود کنید، مثلاً `--image-scope ".texture-gallery"`.
- **آدرس عکس‌ها داخل کد جاوااسکریپت است** (مثلاً در گالری‌ها): `--scan-scripts` را اضافه کنید.
- **عکس‌ها اصلاً پیدا نمی‌شوند**: `--render` را امتحان کنید.
